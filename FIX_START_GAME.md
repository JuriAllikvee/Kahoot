# Как исправить проблему с запуском игры

## Проблема
Игра создается, игроки заходят в лобби, но кнопка "Start game" не работает.

## Причина
В коллекции `games` отсутствуют обязательные поля для управления состоянием игры.

## Решение: Добавить поля в PocketBase Admin

### Шаг 1: Открыть PocketBase Admin
Перейдите по адресу: http://pocketbase-bzmqz78h0ehdz5mnq2t4eumx.176.112.158.15.sslip.io/_/

### Шаг 2: Войти в админку
Используйте логин и пароль администратора PocketBase.

### Шаг 3: Открыть коллекцию `games`
1. В меню слева выберите **Collections**
2. Найдите коллекцию **games**
3. Нажмите на иконку редактирования (карандаш)

### Шаг 4: Добавить поля

#### Поле 1: questionDeadline
1. Нажмите **New field**
2. Выберите тип: **Date**
3. Name: `questionDeadline`
4. Required: **No** (снимите галочку)
5. Presentable: **No** (снимите галочку)
6. Нажмите **Save**

#### Поле 2: questionSnapshot
1. Нажмите **New field**
2. Выберите тип: **JSON**
3. Name: `questionSnapshot`
4. Required: **No**
5. Presentable: **No**
6. Нажмите **Save**

#### Поле 3: questionPosition
1. Нажмите **New field**
2. Выберите тип: **Number**
3. Name: `questionPosition`
4. Required: **No**
5. Presentable: **No**
6. Only integers: **Yes** (поставьте галочку)
7. Min: `0`
8. Нажмите **Save**

### Шаг 5: Сохранить коллекцию
Нажмите **Save** внизу формы редактирования коллекции.

### Шаг 6: Проверить работу
1. Создайте новое лобби как host
2. Зайдите как игрок
3. Нажмите "Start game"
4. Должен появиться вопрос с таймером

## Альтернатива: Импорт обновленной схемы

1. В админке PocketBase: **Settings** → **Import collections**
2. Выберите файл `pb_schema.json` из репозитория
3. Нажмите **Review** → проверьте изменения
4. Нажмите **Import**

⚠️ **Внимание**: Импорт перезапишет все коллекции. Если у вас есть данные, сделайте бэкап!
