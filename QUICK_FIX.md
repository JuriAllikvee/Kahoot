# Быстрое решение проблемы с запуском игры

## Проблема
Лобби создается, игроки заходят, но игра не запускается.

## Причина
В базе данных не хватает полей.

## Решение (2 минуты)

### Вариант 1: Импорт схемы (рекомендуется)

1. Откройте PocketBase Admin: http://pocketbase-bzmqz78h0ehdz5mnq2t4eumx.176.112.158.15.sslip.io/_/
2. Войдите в админку
3. **Settings** → **Import collections**
4. Выберите файл `pb_schema.json` из репозитория
5. **Review** → **Import**

✅ Готово! Все поля добавлены автоматически.

### Вариант 2: Добавить поля вручную

Откройте коллекцию **games** и добавьте 3 поля:

1. **questionDeadline** (Date, не обязательное)
2. **questionSnapshot** (JSON, не обязательное)
3. **questionPosition** (Number, целое, мин: 0, не обязательное)

## Проверка

1. Создайте новое лобби
2. Зайдите как игрок
3. Нажмите "Start game"
4. Должен появиться вопрос

## Дополнительно

Файл `pb_schema.json` уже обновлен и содержит все нужные поля.
